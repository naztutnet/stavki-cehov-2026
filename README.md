# KinoRates — справочник ставок

KinoRates — отраслевой справочник рекомендованных ставок специалистов кинопроизводства и конструктор предварительной сметы.

Сайт: https://kinorates.ru/

## Структура

- `index.html` — основной интерфейс справочника и конструктора сметы.
- `rates-data.js` — база ставок, загружаемая отдельно от интерфейса.
- `stavki-kinotsekhov/`, `smeta-filma/`, `operatorskiy-tsekh/`, `rezhisserskiy-tsekh/`, `hudozhestvennyy-tsekh/` — SEO-страницы.
- `seo-pages.css` — общие стили SEO-страниц.
- `updates.js` — журнал обновлений сервиса.
- `check-log.js` — журнал автоматических проверок источников.
- `data/monitored-sources.json` — список контролируемых первоисточников.
- `data/source-state.json` — последнее зафиксированное состояние источников.
- `scripts/check_sources.py` — проверка изменений в первоисточниках.
- `.github/workflows/check-rate-sources.yml` — плановый запуск проверки источников.

Ставки носят рекомендательный характер. Перед договором или защитой сметы проверяйте дату, единицу расчёта, условия и первоисточник каждой позиции.
