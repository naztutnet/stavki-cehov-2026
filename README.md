# KinoRates — справочник ставок

Единая версия отраслевого справочника ставок и конструктора предварительной сметы.

Сайт: https://kinorates.ru/

Сайт состоит из одной страницы — `index.html`. Конструктор сметы открывается внутри неё без перехода на другую страницу.

Дизайн и публикация не являются аудитом ставок. Перед договором или защитой сметы проверяйте дату и первоисточник каждой позиции.
